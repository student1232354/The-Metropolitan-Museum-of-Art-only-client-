# The Metropolitan Museum of Art Landing Page

## Introduction
This project is a single-page landing website for The Metropolitan Museum of Art, implemented from a Figma design. The page introduces visitors to the museum's schedule, ongoing exhibitions, online exploration areas, and contact details. Built with modern frontend tools, it focuses on visual harmony, responsiveness, and accurate alignment with the design layout.

## Key Features
- **Responsive Design:** The page is optimized for multiple screen sizes, including desktop (1280px), tablet (744px), and mobile (>320px).
- **Header with Burger Menu:** Provides a navigable interface that adapts seamlessly to different screen sizes, featuring quick hover-revealed contact numbers and full-screen menu navigation.
- **Schedule Section:** Presents clear museum opening hours and special operating days with structured typography.
- **Exhibitions Showcase:** Features asymmetric photo grids and detailed information for current museum exhibitions with smooth hover animations.
- **Explore Online Section:** Highlights collection areas, travel programs, and virtual group tours with balanced card layouts.
- **Contact & Feedback Form:** Allows visitors to send messages via a styled feedback form and view museum location and contact details.
- **Footer:** Contains a full-width visual banner and structured contact information for quick access.

The project is built with HTML5, CSS3, Sass (SCSS), JavaScript, and Parcel for bundling and optimizing the website. Both the layout and styling closely follow the Figma mockup and use the Cinzel and Roboto fonts.

## Challenges
As this was an in-depth experience in creating a comprehensive landing page for a museum, several challenges emerged throughout the development process. One notable challenge was implementing a fully responsive layout that accurately reflects the Figma mockups across every breakpoint.

## Key Challenges:
1. **Responsive Design Complexity:** Ensuring the page looked and functioned well across various devices required meticulous attention to detail. Adapting multi-column layouts, asymmetric image grids, and typography to fit desktop, tablet, and mobile screens involved extensive testing and fine-tuning of SCSS styles.
2. **Burger Menu Implementation:** Integrating a full-screen burger menu that worked seamlessly across different screen sizes posed technical challenges. Ensuring that the menu was both functional and aesthetically pleasing required smooth CSS transitions, proper positioning, and scroll locking.
3. **Interactive Elements & Hover Animations:** Implementing smooth hover effects for navigation links, phone contacts, and exhibition cards while keeping the interface clean and performant required careful styling and state transitions.
4. **Form Styling and Smooth Navigation:** Ensuring that the contact form inputs were user-friendly, responsive, and properly aligned, alongside smooth scrolling between page sections, required thorough testing and debugging.
5. **Code Quality & Browser Compatibility:** Adhering to strict BEM naming conventions, Stylelint property ordering rules, and ensuring consistent rendering across different browsers required careful structuring and refactoring of the SCSS codebase.

Despite these challenges, overcoming them significantly contributed to my growth as a developer. The experience enhanced my skills in responsive layout architecture, BEM/SCSS methodology, JavaScript interactions, and cross-browser compatibility, providing valuable insights into practical frontend development.

## Technical Requirements
To run this project, you will need:
- Node.js (version 14.x or newer)
- NPM (version 6.x or newer)

## Installation and Setup
To install the project and run it locally, follow these steps:

1. Clone the repository:
```bash
   git clone https://github.com/student1232354/The-Metropolitan-Museum-of-Art-only-client-.git
```
2.   Navigate to the project directory:
```bash
    cd The-Metropolitan-Museum-of-Art-only-client-
```
3. Install dependencies:
```bash
  npm install
```
4. Start the local development server:
```bash
  npm start
```

## Usage
After starting the project, it will be available locally in your browser (typically at http://localhost:8080).
